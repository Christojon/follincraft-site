Sheet Metal Weight Calculator

HTMLJavaScriptGoogle Sheets
Overview

Accurately calculate sheet metal weight for planning.

This project started as a faster way to estimate sheet weight from dimensions, thickness, quantity, and material density. The current browser version keeps the calculation immediate and avoids making someone open a spreadsheet for a single shop-floor answer.

It is useful for material planning, shipping estimates, load checks, and catching an unrealistic handling assumption before a sheet is ordered or moved.
